# Домашнее задание: Асинхронность в Python (Асинхронный загрузчик URL)

В этом репозитории представлено решение заданий по теме асинхронного программирования. Каждое задание вынесено в отдельный файл. В начале каждого файла (в docstring) приведены необходимые объяснения и замеры времени.

## Структура проекта

*   `task0.py` — Задание 0. Разминка-ловушка «Почему не быстрее?». Демонстрация проблемы последовательного `await` и исправление через `asyncio.gather`.
*   `task1.py` — Задание 1. Синхронно vs Асинхронно. Сравнение скорости работы `requests` и `httpx.AsyncClient`.
*   `task2.py` — Задание 2. Реальный I/O и обработка ошибок. Реализованы таймауты, ретраи с экспоненциальным backoff и изоляция падений (битые URL не роняют программу).
*   `task3.py` — Задание 3 (*). Вынос CPU-bound-вычислений. Демонстрация блокировки event loop при тяжелых вычислениях и решение через `ProcessPoolExecutor`.
*   `requirements.txt` — список зависимостей.
